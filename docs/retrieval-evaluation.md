数据集：`evaluation/retrieval-v1.json`，开发集30条、保留集30条，含相似术语、相同问题改写、版本说明和无答案问题。语料：`evaluation/corpus.json`，8份虚构演示文档、64个有效切块，另有停用旧版演示切块。数据哈希由 `evaluation/frozen-sha256.json` 记录。

四组必须使用同一语料、同一题集、相同topK。语义融合只有在保留集Recall@5不低于BM25＋哈希、且同义表达子集改善时才成为推荐配置；未满足时保留为实验结果，继续推荐现有默认。

正式报告应包含逐题ranked结果、Recall@5、MRR、延迟、token用量、错误与误拒答分类、配置指纹、数据库守卫状态。未获取token用量时明确为缺失，未提供价格时不估算成本。保留集只用于冻结后的比较，不用其错误案例调参后再次宣称为独立验证。

报告会读取 `GET /api/m10/retrieval-tests/manifest`，核对全部在线语料与每块内容哈希，而不是把新增64块当成整个在线库。原有启用文档也进入同一候选集。每个策略运行后重新比较快照；改变语料或模型配置则终止并保存失败证据。

Recall@5 与 MRR@5 的分母只包含有相关块标注的题。无答案题单列候选返回数，它不等于问答误答率；误答与误拒答由问答评测单独报告。每个 family 的第二个冻结改写（ID 后缀 `-2`）预先指定为同义表达子集，未据保留集结果挑选。

每次运行创建唯一结果目录，逐题即时写入 evidence.jsonl。中途HTTP失败、索引失效或策略降级会保留部分报告并标记 complete=false，不产生语义融合推荐。未完成保留集比较时继续推荐 BM25＋哈希。
