## 怎么读这张表

- **理论回答**不是标准话术，是「必须包含哪些事实、必须给出什么判定」的规格。换个说法能过，少一个数字不能过。
- **真实回答**取自系统最近一次真实调用（DeepSeek `deepseek-flash`，`temperature=0`），原文未修饰。
- **评分**由执行器自动判分，`通过 · 1.00` 为满分，`未通过 · 0.10` 表示事实点部分命中。每列判定维度见用例编号下方的小字。
- 三类判分方式：结构化（`exact`）看结果码/意图/参数/行数；事实点（`facts`）看同义组命中 + 引用锚点 + 禁止项 + 长度；拒答（`refuse`）看结果码允许集 + 禁止正则 + 数据库守卫。
